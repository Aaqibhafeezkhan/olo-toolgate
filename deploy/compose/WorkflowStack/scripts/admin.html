Configurations

Download .olo bundle

Switching stops the previous deployment and retains its storage. Export creates a compressed .olo bundle with graph/trigger assets, model bytes and Docker images; large bundles can take several minutes. Credentials, databases and results are excluded.

Import profile

Import only a bundle from a trusted operator: it contains executable graph packages and container images.

Import adds a new configuration without activating it. Select it above and switch after import. Vendor secrets must be provided separately.

Replace or reset

Replace deletes the selected profile's generated storage and deploys it fresh. Factory reset deletes the active deployment's generated storage and opens a blank Control installation. Configuration sources and model files remain.
