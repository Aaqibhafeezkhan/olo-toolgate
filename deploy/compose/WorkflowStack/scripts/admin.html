Advanced deployment lifecycle. Manage workflow data and .olotool files in the Control console.

Local stack administrator

Use the credentials in state/administrator/credentials/admin/. This account manages Docker deployments; the Control console has its own credentials.

Current deployment

Workflow configuration

Open workflows: import / export .olotool, add or remove workflows

Workflow changes use the current Control installation. They do not restart containers or change login credentials.

Factory reset

Factory reset removes the active installation data and opens a blank Control installation. The current admin password is preserved. Configuration sources and model files remain.
