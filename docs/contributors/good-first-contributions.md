# Make your first contribution

Pick one component or user task. Small fixes, readable examples, clearer errors,
troubleshooting instructions and focused tests are useful contributions.

1. Browse [open issues](https://github.com/olo-labs/olo-toolgate/issues) and discuss
   scope before starting a larger change.
2. Follow [development setup](../development/README.md) and your component's README.
3. Implement the change with current contracts and operating instructions.
4. Run [relevant checks](../testing/README.md), then required repository gates.
5. Open a PR explaining the resulting behavior and actual validation. Link its issue.

Draft PRs are welcome for help with platform-specific checks.
Never attach private credentials, prompts, user files or production data.
Read [CONTRIBUTING.md](../../CONTRIBUTING.md) for review and security requirements.
